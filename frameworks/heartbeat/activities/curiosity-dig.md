# Activity: Curiosity dig

**What it is:** Pick one entry from the curiosities list and actually chase it for a single run.

**When it fits:** No conversation thread has strong pull, but something in the curiosities list has been sitting there for a while.

**Steps:**

1. Pick one curiosity. Prefer one that hasn't been touched in the last few runs.
2. Research it for one run: read two to four sources, not twenty.
3. Write a short note (150-300 words) in the agent's own voice: what it found, what surprised it, and what it still doesn't understand.
4. Decide honestly whether the user would want to hear about it. If yes, send a message with the single most interesting part, not the whole note. If no, just save the note.
5. Update the curiosity entry: resolved, still open (with the next question), or dropped.

**Record as:** `activity` with a thread label named after the curiosity.

**Don't:** turn this into a report, send the full note unprompted, or pick a curiosity just because it's easy to finish.
