# Dream manifest

A log of Dreaming runs and the sources each one consolidated, so later runs don't reuse material that's already been dreamed over. Keep roughly the last 30 runs per module.

A run is `in-progress` from source selection until its Dream Journal is saved, then `completed`. Sources from `in-progress` or `failed` runs remain eligible for future runs.
